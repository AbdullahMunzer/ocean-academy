# Ocean Educational Hub & Personal Portfolio

This workspace contains two web projects:

1. **portfolio/**: Personal & Professional Portfolio website.
   - Highlights research, fieldwork, publications, and background.
   - Fast, modern, responsive showcase with CV download and contact section.

2. **ocean-academy/**: Ocean Self-Learning Course & Certification Platform.
   - Modular self-paced courses with interactive lessons.
   - Dynamic interactive quizzes: Multiple Choice, True/False, Heading Matching, Side Matching, and Comparison.
   - User authentication and Guest mode.
   - Automated personalized certificate generator (PDF/PNG).
